# meest-bonus-app

## Редактирование справочников

В приложении выберите файлы справочников магазинов и директоров, откройте раздел «Редактировать справочники магазинов и директоров» и нужную вкладку. В таблице можно изменить значения, добавить новые строки или удалить существующие, затем нажать «Сохранить изменения».

Выбранные файлы `.xlsx` сохраняются сразу на компьютере, где запущено приложение. Для загруженного с компьютера файла нужно скачать обновленный вариант отдельно; локальный файл `.xls` можно скачать после редактирования в формате `.xlsx`. Номера отделений и табельные номера должны быть положительными и уникальными; обязательные поля нужно заполнить во всех строках.

## Новые магазины из реестров

При формировании отчета приложение проверяет отделения из загруженных реестров. Если отделения еще нет в справочнике, отчет приостанавливается и просит указать название магазина и директора; номер отделения подставляется автоматически. Если в реестре заполнена колонка «Підрозділ», ее название предлагается автоматически. Первым вариантом директора предлагается добавить нового, также можно выбрать директора из справочника. Для нового директора нужно указать табельный номер и ФИО. После сохранения магазин и его связь с директором добавляются в справочник магазинов, а новый директор — в справочник директоров; затем отчет формируется с новыми данными.

This app helps to calculate and distribute Meest delivery bonuses.
